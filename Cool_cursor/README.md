# REgenOS Cool Cursor Artwork

Original artwork by Aryan, created from scratch in RealWorld Cursor Editor.
The author confirmed authorship and requested inclusion as REgenOS's default
cursor pack on 2026-09-26. These are editable Windows source assets, not Linux
cursor files. See [Linux installation](../docs/CURSOR_THEME.md).

The author's request authorizes inclusion in REgenOS. No broader standalone
artwork license has been specified; do not assume the source-code license
applies to these assets. Retain this attribution when shipping the theme.

`Cool_busy.ani` supplies animated wait/progress; `Cool_Select.cur` supplies help.
Location and Person are preserved as named custom roles because Linux has no
direct equivalents for these Windows cursor roles. Missing roles inherit Adwaita; they are not
silently assigned an unrelated pointer.
