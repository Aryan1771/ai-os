# REGENOS Branding Assets

Keep only original assets here. The installer expects these optional files:

```text
branding/regenos-mark.svg
branding/regenos-mark.png
branding/regenos-companion-atlas.png
branding/wallpapers/default.png
branding/wallpapers/lockscreen.png
branding/wallpapers/default.svg
branding/wallpapers/lockscreen.svg
branding/plymouth/regenos.plymouth
branding/plymouth/regenos.script
```

Do not commit copyrighted third-party logos or downloaded desktop themes unless their license permits redistribution.

The atlas contains nine retro pixel poses for the companion. The desktop overlay currently uses a separate spring-driven particle renderer for expression and a small set of topic silhouettes; arbitrary subject illustration is not generated yet.
